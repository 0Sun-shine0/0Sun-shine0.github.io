装备

我在用什么

这份清单只写我用了半年以上的东西，短命尝试过的工具就不列了。 硬件那栏我没什么讲究，一台 Windows 11 机器跑完开发、打包和发布。

语言与框架
主力语言
Python（桌面与 AI 工具）和 TypeScript（Electron 桌面端）。
桌面 UI
PySide6 + Qt Quick / QML。GPU 渲染的矢量画面，真圆角真阴影，60fps 缓动。
Web 技术
Electron + React + Vite，用来做 Agent 的图形界面。
脚本
PowerShell 写 Windows 上的自动化；R 只用来跑统计脚本。
运行环境
系统
Windows 11。开发、打包、发布都在这一台机器上。
Python
3.12（项目自带 .venv 隔离，绝不装进全局）；本机另有 3.14 用于随手脚本。
依赖哲学
小爪助手的运行依赖只有一个：PySide6-Essentials。依赖越少，装完就能用的概率越高。
Node
v24，只服务于 Electron / 前端项目，以及本站（Astro）。
编辑器与工具
编辑器
VS Code 写 Python / TS，Trae CN 用来做代码补全。
数据库
DataGrip 查数据；小爪自己的数据是 JSON + 原子写，不引入数据库。
笔记
Typora 写 Markdown —— 项目的 README 和文档都是这么来的。
抓包
Fiddler，调外部 API 时用。
版本控制
Git + GitHub，一个项目一个仓库。
打包与发布
打包
PyInstaller（onedir），再用自己写的 tkinter 向导做成单文件安装程序，约 120MB。
产物
安装程序、绿色版 zip、未压缩运行目录三份，分别对应「发给别人」「塞 U 盘」「自己调试」。
自测
tools/ 下 107 个脚本（其中 50 个是回归测试）。打包前先跑一遍，不通过就不出包。
调试方式
比起打断点，我更常写一次性回归脚本 —— 它能留住上次踩过的坑，下次自动帮你挡住。
关于折腾环境这件事
这套环境我已经换过很多轮了。现在比起折腾环境本身，我更想把时间留给真正想做的东西。

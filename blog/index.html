不想写成「从零开始」教程。这里只有我在折腾桌面工具和自动化时踩过的坑：当时是怎么找到问题的，怎么解决的，以及下次会不会又栽进去。

2026-10-02让“渲染结果”当唯一真相，而不是再画一遍透明窗口的点击区域、拖拽时的边框高亮、滚动时的卡片阴影 凡是要跟画面保持一致的东西，我在两个项目里都栽在同一件事上：把它描述了两遍。
2026-10-01一道题选哪个数：我踩过的三次「阈值」坑分镜密度、细节强度、光流冻结 三个不同领域的问题，最后都归结成同一件事：挑一个数，然后说清它是怎么来的。挑数字比写算法难。
2026-09-30我写过两个「假指标」，直到它们骗了我自己一个拿轮廓个数当物体检测、去跟关键词个数比大小；一个直方图相关系数低于 0.7 就报警。两个都跑得通、都看着合理，但都没有意义。附一个能说明问题的实测：同一张图与其压缩首帧的 SSIM 是 0.998，直方图相关系数却是 -0.0015。
2026-09-27我是怎么做出一个能双击安装的版本的把 Python 桌面应用做成「双击、下一步、完成」，比写功能更容易漏细节。打包流水线、自己写的安装向导、会自删的卸载器，以及安装版和绿色版怎么共用一套程序。
2026-09-25确认次数和截图成本，最后是同一个问题做桌面操作工具，体验一半卡在确认弹窗太多，一半卡在截图太贵 —— 而这两件事在成本上是同一件事。
2026-09-23我给桌面操作加的两道硬限制小爪能操作键鼠、读文件、跑命令，所以有两个动作即使在「完全自动」下也要再问一次。为什么这么分，以及这类判断该写在审批链的第几行。
2026-09-21一条数据为什么会悄悄退回备份待办没报错，却少了几条。查到是 UTF-8 BOM 让 json.load 抛了异常，程序又把它当成文件损坏、静默回退到备份 —— 数据看起来就「凭空少了」。
2026-09-18桌面宠物怎么做到“点得穿”无边框透明窗口会整块吃掉鼠标事件 —— 点宠物旁边的「空气」，其实点在窗口上。我没在 Python 里重画一遍宠物形状，而是拿渲染结果的 alpha 通道去生成窗口遮罩。
2025-05-18测试怎么写才不花 API 钱我做的项目几乎全依赖外部接口 —— 语言模型、视觉生成、视频合成。跑一次全量测试要烧掉几十块。后来用了三层替身，现在本地跑 294 个用例，一分钱不花。
2024-08-11四种限流算法，我为什么选了最笨的那个2024 年第一次做需要限流的项目，我把四种经典算法都抄了一遍，最后用了最简陋的固定窗口计数器。真实原因是：只有它我完全看得懂。
2024-03-16从一道「字符串解码」看边界条件是怎么漏掉的第一次认真刷算法题，思路三分钟就想出来，然后连挂四次。写得比较啰嗦，因为那时候我确实没想清楚，只想把过程记下来。
